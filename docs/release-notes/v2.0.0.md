TeddyBench now runs on **Linux**. This release is the result of porting Teddy/TeddyBench from .NET Framework 4.8 and WinForms to **.NET 10** with a new cross-platform GUI built on **Avalonia**.

## Downloads (Linux, x86_64)

| File | What it is |
|---|---|
| `TeddyBench-x86_64.AppImage` | `chmod +x` it and start it. Runs the GUI; `./TeddyBench-x86_64.AppImage cli --help` runs the command line tool. |
| `TeddyBench-linux-x64.tar.gz` | Unpack and run `./install.sh`: installs for your user into `~/.local`, with a menu entry and the commands `teddybench` and `teddy`. `./install.sh --uninstall` removes it. |

Both are self-contained (no .NET installation needed) and run on x86_64 distributions with glibc.

## What's new

- **Command line tool `Teddy`** (encode / decode / info) runs natively on Linux.
- **New GUI** with the features of the WinForms TeddyBench:
  - card content with covers and sort modes;
  - add (encode MP3/Ogg or copy tonie files), delete, save as .ogg, export, assign a new UID, live flag, rename;
  - NFC reader support (Proxmark3, PN5180), antenna plot, diagnostics reports, update check.
- **Linux integration:**
  - the inserted SD card is opened automatically;
  - the live flag (FAT hidden attribute) works on the card;
  - audio preview through PipeWire, PulseAudio or ALSA;
  - "show in file manager".
- **NFC readers on Linux:** only USB serial ports are probed. The status bar explains a missing `dialout` group membership. `77-teddybench-readers.rules` (in the tarball) keeps ModemManager away from the Proxmark3.
- **Settings and data** are stored in `~/.config/TeddyBench` and `~/.cache/TeddyBench`.

## Fixes (also affecting Windows)

- Encoding Ogg input files failed: the bit rate was passed as the sample rate.
- MP3 track numbers written by ffmpeg and many other taggers were not read, so tracks were sorted by file name.
- Starting without "download tonies.json" read the wrong file and showed no tonie names.
- File names created from tonie titles could contain characters that are invalid on the FAT SD card.
- The update check only offers newer releases, and finds its file among several release assets.

## Notes

- MP3 decoding now uses a managed decoder and resampler instead of the Windows codecs. Generated tonie files are therefore not byte-identical to ones from older Windows builds; the audio is equivalent.
- The Windows build of TeddyBench is still the original WinForms version. The new GUI has not been tested on Windows yet.
- Not yet tested with real Proxmark3/PN5180 hardware on Linux. Feedback is welcome.
